Make an access code hash

Type a new access code. This page turns it into a "hash" — a scrambled version you can safely put in config.js. The code itself never leaves this page.

What to do next

  1. Open config.js in your GitHub repository and click the pencil (Edit) icon.
  2. Find the list called ACCESS_CODE_HASHES.
  3. Paste the copied line on a new line inside the square brackets [ ], below the other codes.
  4. Click Commit changes. The new code works within a few minutes.

Codes are not case-sensitive and extra spaces are ignored, so sal-2026-abcd and SAL-2026-ABCD are the same code.
